## Electron

Simulator for bonds and atoms and alike. I'm not a chemist, not even in the slightest - the extent of my knowledge is middle school. So if there are any logical fallacies, please open an issue (or make a PR).

The code here is messy, I didn't read it. It was supposed to be just a fun expirement.

Try it out [here](https://kk-spartans.github.io/electron).

## Docker + AI reactions

GitHub Pages serves the static export, while the Docker image runs the same
static export behind a tiny Bun server that also listens on `/api/reactions`.
When the site can reach that endpoint it augments the static index with
model-predicted reactions (and asks the model to enumerate every distinct
balanced form); when it cannot (e.g. on GitHub Pages), it falls back to the
static index alone. The server caches model responses on disk
(`REACTION_CACHE_DIR`), so repeated requests for the same species never hit
the model provider twice.

The image is built with Nix (`nix build .#docker`) and the compose file is
generated by [arion](https://github.com/ariel-miculas/arion).

Configure the model provider via env vars (see `.env.example`):

| Variable             | Description                                 | Default                     |
| -------------------- | ------------------------------------------- | --------------------------- |
| `OPENAI_BASE_URL`    | OpenAI-compatible chat completions base URL | `https://api.openai.com/v1` |
| `OPENAI_API_KEY`     | API key for the provider                    | _(none)_                    |
| `OPENAI_MODEL`       | Model to use for reaction prediction        | `gpt-4o-mini`               |
| `ELECTRON_PORT`      | Host port mapped to the container's `8080`  | `8080`                      |
| `REACTION_CACHE_DIR` | Where the server persists AI response cache | `.cache/ai-reactions`       |

Build and run:

```sh
nix build .#docker
docker load < result
docker compose -f devops/docker-compose.yml up
```

`devops/docker-compose.yml` is generated from `devops/arion-compose.nix`:

```sh
devenv tasks run electron:compose
```
